# Logical Flow Check Reference

Use this reference for recurring slide-logic problems, optional scoring, and a reusable report structure. The main skill does not require all sections for every review.

## Common problem shapes

| Axis | Slide symptom | Missing relation | Small repair |
|---|---|---|---|
| Title/body | The title claims causation while the body shows only sequence | Mechanism or narrower claim | Add the mechanism or rewrite the title as an observation |
| Claim/support | One example is used to imply prevalence | Evidence for frequency | Present it as a possibility or add representative evidence |
| Reading order | Columns look sequential but are meant as alternatives | Explicit relation between blocks | Add labels or change the layout to a comparison |
| Question/answer | A slide asks why and the next slide defines what | Answer to the stated question | Answer briefly before changing the question |
| Audience sync | A term carries the punchline before it is introduced | Shared definition or concrete example | Define it before the inference or lead with the example |

Adding an arrow or transition phrase does not repair missing reasoning. Prefer supplying the premise, changing the visual relation, or narrowing the claim.

## Optional scoring

Use scores only when the user requests comparison or tracking. Score each axis from 1 to 5:

- **5** — the intended audience can reconstruct the slide’s inference at presentation speed;
- **4** — isolated weak links do not interrupt the local argument;
- **3** — several links depend on narration or unstated premises, but the claim remains recoverable;
- **2** — repeated missing premises, misleading layouts, or unanswered questions interrupt understanding;
- **1** — titles, support, and conclusions remain largely disconnected.

Do not average away a Critical gap. Explain the evidence behind each score.
